yeah so you can like, input arbitrary autohotkey scripts into the little boxes, then hit save, it'll execute that script when you hit the button.

otherwise, input something like {Left} as though it were a single hotkey like ^F1::Up
and it'll also map that hotkey with like, button down -> key down, button up -> key up
and there's also a checkbox for key repeat, and a slider for key repeat.

yeah and the left stick does the mouse cursor movement by default. i found that whatever was going on in antimicrox was not conducive to having the left stick control the mouse cursor accurately. this seems to work pretty great so yeah.
there's some sliders for the mouse cursor movement settings too.
